动漫答题放映器 — 使用说明
================================================

这是一个跑在你自己电脑上的小网页工具。用来放答题：图片、音频、视频都能放，
比 PPT 顺手。不需要联网，不用装任何额外的库。


一、怎么启动
------------------------------------------------

  Windows : 双击 start.bat
  WSL/Linux: 终端里跑 ./start.sh

启动后浏览器会自动打开放映页。用完了直接关掉那个黑色窗口就行。

如果双击 start.bat 报错说找不到 python：
  Windows 上还没装 Python。去 python.org 下载安装，
  安装时记得勾上 "Add python.exe to PATH"，然后重开一次 start.bat。


二、加题
------------------------------------------------

浏览器打开 http://127.0.0.1:8756/admin

  1. 题干：粘进去
  2. 选项：填 ABCD，点选项左边的圆圈把正确答案标出来
  3. 媒体：把图片/音乐/视频拖进虚线框（也可以点它选文件）
       - 图片：可以设"初始模糊"。填个 10-20，放映时就是一张打码图，
              答完题自动变清晰
       - 音频/视频：传好之后会出来一个播放条，点"设为起点""设为终点"，
              就能把这道题限定成只播某几秒。比如只想让大家听副歌，
              听到那一段时点两下就行
  4. 解析、分类：可填可不填
  5. 点保存

页面下方是已有题目，可以改顺序（↑ ↓）、编辑、删除。
按 Ctrl+S 也能保存。


三、每轮怎么出题
------------------------------------------------

  每次开始都是随机抽题，同一轮里不会重复。

    单人模式    抽 5 道题，答完结束，会告诉你答对几道
    双人轮流    轮流作答，答对加一分、答错不扣分，谁先答对 5 道谁赢
                （所以一局的题数不固定，看两个人答得怎么样）

  这几个数字想改的话，在 web/play.js 开头：

    var SINGLE_COUNT = 5;   单人一轮抽几道
    var DUO_TARGET = 5;     双人先答对几道算赢


四、怎么答题
------------------------------------------------

  全部用鼠标点，键盘不用管。

    点对了   →  那一项变成绿色
    点错了   →  你点的那一项变成红色，同时正确答案那一项变成绿色
    然后     →  点右下角的「下一题」

  答完之后会显示这道题的解析（题库里填了才有）。
  已经答过的题再点其他选项不会有反应。


  单人模式

    一轮 5 道题，自己点自己的。放完显示答对几道。


  双人轮流

    屏幕右上角写着「轮到 XXX」，XXX 就是该答这道题的人。
    两个人轮流点选项。点对加一分，点错不扣分。
    谁先答对 5 道，这一局就结束，显示比分和赢家。

    右上角的比分：谁在作答，谁那一块就亮着琥珀底色。
    答对加分的时候，那个分数会放大闪一下。

    轮流是严格的：这一局你点一道、我点一道，不会有人连着点两题。


  键盘只留着控制媒体和退出，不参与答题

    R       重播这段媒体（只重播你定的那一段，不会从头放整首）
    P       暂停 / 继续
    Esc     结束这一轮，回到开始界面

  音频题那个播放条，直接用鼠标点左边的圆角按钮就能播放 / 暂停。


五、配色
------------------------------------------------

  默认浅色（白底）。在首页最下面点一下就能切成深色，这个选择会记住。

  深色适合关灯或者投影的环境，浅色适合亮着灯的教室。


六、文件都在哪
------------------------------------------------

  data/questions.json   题库。所有题目都在里面，纯文本，可以直接备份、
                        拷贝到别的电脑。每次保存时上一版会自动留成
                        questions.json.bak
  media/                所有图片、音频、视频文件
  web/                  界面文件（一般不用动）
  server.py             本地服务程序

备份的办法：把整个 anime-quiz 文件夹复制一份就行。搬到别的电脑也一样，
连 media 文件夹一起拷过去，路径不会断。


七、题目格式（想手动改的时候看）
------------------------------------------------

questions.json 是一个数组，一道题长这样：

  {
    "id": "q6aef8a940eee",
    "question": "这张图出自哪部作品？",
    "options": ["进击的巨人", "鬼灭之刃", "咒术回战", "电锯人"],
    "answer": 0,
    "explain": "答完之后显示的解析",
    "category": "看画面猜番",
    "media": {
      "kind": "image",
      "src": "media/xxx.jpg",
      "start": 0,
      "end": 0,
      "blur": 18
    }
  }

  answer    正确答案在 options 里的位置，从 0 开始数（0 就是第一个）
  media     没有媒体的题可以整块去掉或写 null
  kind      image / audio / video
  start end 音频视频的播放区间（秒）。end 写 0 表示播到结尾
  blur      图片初始模糊，0 表示清晰
  category  放映时显示在左上角的小字。不想要就留空

注意 src 用的是相对路径，以 media/ 开头。手动往里加文件时，
把媒体丢进 media 文件夹，然后照着上面写就行。


八、可能遇到的问题
------------------------------------------------

  放映页打不开 / 一直转圈
    本地服务没在跑。关掉黑窗口，重新双击 start.bat。

  显示"端口被占用"
    8756 这个端口被别的东西用了。用命令指定另一个端口：
      python server.py 9000
    然后手动打开 http://127.0.0.1:9000/play

  音频视频不出声
    浏览器要求页面先有一次点击才能出声。点一下别的地方再按 R 重播就行。

  显示"媒体文件找不到"
    media 文件夹里那个文件被删了或者改名了。重新传一次，或者把文件名改回去。

  点选项没反应
    这道题已经答过了。点右下角「下一题」继续。

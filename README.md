# 动漫答题放映器

跑在本地的小工具，用来办动漫答题活动。比 PPT 顺手：题目和答案分开、音乐只播你要的那几秒、加题不用排版。

## 运行

需要 Python 3，不用装任何依赖。

```
Windows    双击 start.bat
WSL/Linux  ./start.sh
```

浏览器会自动打开 `http://127.0.0.1:8756`。端口被占用了就 `python server.py 9000`。

## 三个页面

| 地址 | 作用 |
|---|---|
| `/play` | 放映答题，现场用这个（全屏按 F11） |
| `/admin` | 题库管理 |
| `/` | 入口，底部可切换浅色 / 深色 |

## 加题

在 `/admin` 里：

1. 填题干
2. 填四个选项，点选项左边的圆圈标出正确答案
3. 媒体可以直接拖进去，也可以粘贴 `https://` 链接
   - 音频视频传完后点「设为起点 / 设为终点」，就能限定只播某几秒
   - 图片可以设初始模糊，放映时是打码图，答完自动变清晰
4. 解析、分类可填可不填
5. 保存（Ctrl+S 也行）

页面下方列着所有题目，能编辑、删除、调顺序。

## 答题

点选项作答，键盘不用管：

- 点对了 → 那一项变绿
- 点错了 → 点的那项变红，同时正确答案变绿
- 然后点右下角「下一题」

单人一轮 5 道；双人轮流作答，答对加一分、答错不扣分，先答对 5 道者赢。

键盘只管媒体：`R` 重播 · `P` 暂停 · `Esc` 结束。

## 题目格式

`data/questions.json` 是一个数组：

```json
{
  "id": "q6aef8a940eee",
  "question": "这张图出自哪部作品？",
  "options": ["进击的巨人", "鬼灭之刃", "咒术回战", "电锯人"],
  "answer": 0,
  "explain": "答完之后显示的解析",
  "category": "看画面猜番",
  "media": {
    "kind": "image",
    "src": "https://example.com/a.jpg",
    "start": 0,
    "end": 0,
    "blur": 18
  }
}
```

| 字段 | 说明 |
|---|---|
| `answer` | 正确项在 `options` 里的下标，从 0 开始 |
| `media` | 没媒体的题可以整块去掉或写 `null` |
| `kind` | `image` / `audio` / `video` |
| `src` | 本地相对路径（`media/xxx.mp3`）或 `https://` 外链 |
| `start` `end` | 播放区间（秒），`end` 写 0 表示播到结尾 |
| `blur` | 图片初始模糊像素，0 表示清晰 |
| `category` | 放映时左上角显示的小字，可以留空 |

## 投稿题目

开 Issue 选「投稿题目」，表单里填题干、四个选项、正确答案、解析。
提交后 Action 会自动转成一道题并开 PR，维护者审核合并即可。

第一次启用前，去 Settings → Actions → General → Workflow permissions
选上 **Read and write permissions**，否则 Action 没权限开 PR。

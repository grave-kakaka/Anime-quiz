# 动漫答题放映器

本地跑的答题放映工具。题目支持文字、图片、音频、视频，比 PPT 顺手。

## 跑起来

需要 Python 3，不用装别的。

```
Windows      双击 start.bat
WSL / Linux  ./start.sh
```

浏览器会自动打开 `http://127.0.0.1:8756`。

## 加题

打开 `http://127.0.0.1:8756/admin`

1. 填题干
2. 填四个选项，点选项左边的圆圈标出正确答案
3. 把图片 / 音频 / 视频拖进去（也可以直接粘 `https://` 链接）
   - 音频视频传完后点「设为起点 / 设为终点」，就能限定只播某几秒
   - 图片可以设初始模糊，放映时是打码图，答完自动变清晰
4. 保存

下面列出所有题目，能编辑、删除、调顺序。

## 答题

打开 `http://127.0.0.1:8756/play`，按 F11 全屏。

用鼠标点选项。点对了变绿；点错了你点的那一项变红、正确答案同时变绿。
然后点右下角「下一题」。

- 单人：一轮 5 道题
- 双人：轮流作答，答对加一分、答错不扣分，先答对 5 道者赢

键盘只管媒体：`R` 重播 · `P` 暂停 · `Esc` 结束。

## 题目存哪

| 路径 | 说明 |
|---|---|
| `data/questions.json` | 题库，纯文本 |
| `media/` | 图片、音频、视频 |

备份或者换电脑，把整个文件夹拷走就行。

想手写题目的话，一道题长这样：

```json
{
  "question": "这张图出自哪部作品？",
  "options": ["进击的巨人", "鬼灭之刃", "咒术回战", "电锯人"],
  "answer": 0,
  "explain": "答完之后显示的解析",
  "category": "看画面猜番",
  "media": { "kind": "image", "src": "media/a.jpg", "blur": 18 }
}
```

`answer` 是正确项的下标（从 0 开始）。没媒体的题把 `media` 去掉或写 `null`。
`kind` 可以是 `image` / `audio` / `video`；音频视频用 `start` `end` 限定播放区间（秒）。
